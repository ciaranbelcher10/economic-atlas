Unemployment is sourced from MoSPI's own Periodic Labour Force Survey (PLFS) via their eSankhyiki API — monthly Current Weekly Status data, only available from 2025 onwards since MoSPI only started publishing at monthly frequency this year. Requires a personal API token (MOSPI_API_KEY); until that's configured this chart won't populate. On the roadmap: employment and participation rates, and wage growth.
