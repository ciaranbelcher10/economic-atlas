Summary

Click any column to sort. Shows whatever point in time or change window is selected above. The highest value in each column is underlined in navy, the lowest in blue: a neutral marker of the extremes, not a judgement on which is better. Every figure is anchored to the exact same calendar year (or window) for every country and metric shown — the small year under each number is that reference year, computed by averaging each country's own real observations within it, so nothing here compares figures from different points in time.

← Swipe to see more columns →

Figures: ONS, FRED, Eurostat, e-Stat/Bank of Japan, MoSPI, Bank of Korea and OECD, the same sources already cited on each country's own page. Every figure on this page is anchored to a specific calendar year -- in Point in time mode, that's whichever year the slider is set to; in Change over time mode, it's the change between the two years the slider spans. Where a metric is published more often than annually, the year's figure is the average of that year's real observations, not a single point-in-time reading. GDP growth over a change window shows total real growth across that period, compounded from each country's own real GDP level. A slower annual-only metric like FDI, current account or the government deficit can show "n/a" for a given year if its own latest published figure hasn't caught up yet -- that's a real, honest gap in the underlying data's timing, not a missing figure or a bug. Currency-denominated figures (GDP, government debt, trade) are converted to US dollars at today's exchange rate so every country is shown in the same unit in Point in time mode; a Change over time window is shown as a % instead, which doesn't need converting since the ratio is the same in any currency. Morocco has no live exchange-rate source for the dirham, so its currency figures show "n/a" rather than a converted guess. Historical lines (Line view) are also converted to USD at today's rate throughout, so older years are an approximation. The Eurozone doesn't appear on any card's map, since it isn't a single country UN Comtrade or world-atlas can plot; it still appears in every chart and table above. Privacy · Terms ·
